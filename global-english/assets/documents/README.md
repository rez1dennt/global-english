# Документы школы

Добавьте утверждённые школой PDF с точными именами:

- price-list.pdf — прайс-лист;
- license.pdf — образовательная лицензия;
- offer.pdf — договор оферты;
- privacy.pdf — политика конфиденциальности;
- consent.pdf — согласие на обработку персональных данных.

Тема автоматически заменит статусы ожидания на ссылки. Не переименовывайте посторонний документ для заполнения пустого места. Содержимое и реквизиты должны быть согласованы владельцем сайта.
