# Слайдер педагогов — 04.09.2026

Добавлены шесть нейтральных SVG-заглушек вместо ещё не предоставленных фотографий. Без имён и личных данных. При заполнении teacher_photos используются реальные локальные фото. Карусель расположена после вступительного текста и перед неизменённой карточкой руководителя. Старый статический вывод team-gallery после руководителя удалён.

Бесконечное листание в обе стороны реализовано скрытыми от accessibility-дерева клонами, transform-переходом и незаметным сбросом позиции. Есть стрелки, drag, touch swipe, клавиатура, счётчик и aria-live. Автопрокрутки нет. На ПК четыре карточки, на планшете две, на телефоне одна. При reduced motion движение выключено. Без JavaScript остаётся горизонтальная галерея. При недостаточном количестве настоящих фото избыточная прокрутка отключается.
