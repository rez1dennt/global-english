# Прайс-лист: стабильное раскрытие — 04.09.2026

Исходная причина движения: price-layout использовал align-items:center, поэтому мгновенное увеличение правой карточки пересчитывало вертикальное положение левой колонки. Дополнительно обе колонки могли ещё завершать data-reveal при раннем клике. Нативный details открывал содержимое без закрывающей анимации и конфликтовал с первоначальным управляемым состоянием.

Исправление: обе колонки закреплены align-items:start; data-reveal снят только с интерактивного блока стоимости. Нативный details заменён доступной кнопкой aria-expanded/aria-controls с управляемыми closed/opening/open/closing состояниями. Контент анимирует grid-template-rows + opacity 420 мс; стрелка синхронно поворачивается. При закрытии содержимое остаётся в DOM до конца перехода, но сразу получает aria-hidden/inert. Escape закрывает и возвращает фокус. Reduced motion переключается сразу. Без JS пояснение видно и остаётся доступным.
