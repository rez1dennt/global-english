# Hero по оригинальному баннеру

ВАЖНО: последующее уточнение пользователя отменяет вставку целого баннера. Актуальная реализация: imagegen очищает фон с мальчиком от надписей, логотипов и плашек; видимый h1 Global English, подпись школы, телефон и предложение — HTML, логотип — SVG, кнопка — ссылка с существующим модальным обработчиком. На мобильном — CSS grid, без растровых надписей. Тест hero-banner-qa.mjs обновлён на видимый DOM-текст и отсутствие невидимых зон-ссылок, проходит семь размеров. Прежнее решение ниже сохранено как история отклонённого подхода.

Уточнение пользователя: заменить прежнюю свободную композицию точным оформлением приложенного рекламного баннера. Меняем только hero, не остальные блоки или палитру сайта. Пользовательские материалы разрешены самим запросом; генерация новых изображений не нужна.

Решение: широкий оригинал целиком через picture на ПК, предоставленный вертикальный вариант до 640 px. Без кадрирования/искажений. Доступный h1, описание баннера, кликабельная зона номера телефона, существующий CTA и модальная форма. Оригинальные файлы не изменять. WebP для веса и скорости.

Проверки: сначала RED на отсутствии баннера; затем исходные пропорции, выбор mobile/desktop, минимум 44 px для телефона, один h1, отсутствие старой композиции, отсутствие переполнения и работа модалки на 1440/1280/1024/768/640/360/320. После этого полная регрессия, скриншоты, новая ZIP-сборка с сохранением старой.
