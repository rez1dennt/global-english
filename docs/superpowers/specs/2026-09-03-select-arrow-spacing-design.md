# Global English: отступ стрелки выпадающего списка

Дата: 03.09.2026

## Цель

Убрать визуальную прижатость стрелки `select` к правой рамке в нижней и модальной формах, сохранив нативное поведение выпадающего списка.

## Причина дефекта

Оба поля используют общее правило `.form-field select` с обычным браузерным оформлением. Системная стрелка Chrome располагается почти у правой рамки и не перемещается через `padding-right`: внутренний отступ влияет только на текст.

## Решение

- Оставить HTML и нативную механику `select` без изменений.
- Для `.form-field select` отключить только системное изображение стрелки через `appearance: none`.
- Использовать отдельный локальный SVG `assets/icons/chevron-down.svg` как декоративный фон.
- Разместить стрелку по центру высоты на расстоянии `var(--space-4)` — 16 px — от правой рамки.
- Зарезервировать справа `var(--space-10)` — 40 px — чтобы текст и стрелка не пересекались.
- Сохранить существующие высоту, фон, рамку, скругление, hover, focus, ошибку валидации и клавиатурное управление.
- В режиме `forced-colors` вернуть системное оформление и убрать фоновую SVG, чтобы системная тема высокой контрастности управляла индикатором.

## Проверка

- Сначала браузерный тест должен упасть, пока у `select` нет требуемых `appearance`, правого отступа и позиции фоновой стрелки.
- После исправления тест проверяет обе формы: `padding-right` равен 40 px, `background-position-x` соответствует отступу 16 px, SVG-фон подключён.
- Визуальная проверка выполняется на 1440, 768, 360 и 320 px.
- Проверяются фокус, открытие списка с клавиатуры, отсутствие горизонтального переполнения и сохранение работы валидации.
