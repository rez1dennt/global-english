# Global English WordPress Theme — дизайн-спецификация

Дата: 2 сентября 2026 г.

## Цель

Создать готовую к установке классическую WordPress-тему для одностраничного сайта языковой школы. Визуальная композиция, порядок секций, тексты, цветовая схема и плотность контента повторяют предоставленный пользователем референс. Фотографии создаются заново в аналогичном визуальном направлении; интерфейсные иконки используются в SVG.

## Технологическая основа

- Классическая PHP-тема без конструктора страниц и обязательных сторонних плагинов.
- Семантический HTML5, CSS с централизованными дизайн-токенами и нативный JavaScript.
- WordPress API для подключения ресурсов, меню, логотипа, формы и безопасной обработки данных.
- Контент и контакты на первом этапе зафиксированы в шаблоне по референсу. Разметка секций сохраняет ясные границы, чтобы затем перенести значения в ACF без перестройки интерфейса.

## Информационная архитектура

Единственная главная страница содержит:

1. фиксированную тёмную шапку с брендом, якорной навигацией, CTA и телефоном;
2. hero-блок с заголовком, подзаголовком, двумя кнопками, студенткой и лондонско-китайским окружением;
3. четыре карточки курсов;
4. четыре преимущества школы;
5. двухколоночный блок методики;
6. блок возможностей изучения языков с четырьмя изображениями;
7. контрастную панель показателей;
8. карточки преподавателей в доступном слайдере;
9. три отзыва учеников;
10. галерею занятий;
11. крупный CTA с формой заявки;
12. тёмный подвал с контактами, навигацией и социальными ссылками.

## Визуальная система

- Основные цвета: графитовый почти чёрный, белый, тёплый жёлтый и мягкий кремовый фон.
- Шрифт: современный геометрический гротеск с кириллицей; заголовки плотные и контрастные, основной текст читаемый.
- Контейнер ограниченной ширины, большие белые поля, карточки с тонкой серой границей, мягкой тенью и скруглением.
- Изображения — тёплая образовательная lifestyle-фотография с естественными лицами, без текста, логотипов и водяных знаков.
- Декоративные элементы и пиктограммы поддерживают школьную, британскую и китайскую тематику, не заменяют доступные текстовые подписи.

## Адаптивное поведение

- Desktop: композиция повторяет референс с многоколоночными сетками.
- Tablet: сетки переходят в две колонки, hero остаётся двухчастным, форма перераспределяется без потери иерархии.
- Mobile 360 и 320 px: одна колонка, укрупнённые зоны нажатия, горизонтальные наборы карточек становятся управляемыми слайдерами или вертикальными списками, изображения получают безопасные кропы.
- Шапка превращается в бургер-меню с блокировкой фонового скролла, закрытием по Escape, клику по ссылке и вне панели.
- Учитываются `prefers-reduced-motion`, клавиатурная навигация и видимый фокус.

## Интерактивность

- Плавная прокрутка к секциям с учётом фиксированной шапки.
- Бургер-меню с корректными ARIA-состояниями.
- Слайдер преподавателей с кнопками, клавиатурным управлением и адаптивным количеством карточек.
- Лёгкие анимации появления секций без блокировки контента.
- Все CTA ведут к форме или соответствующей секции.

## Форма заявки

Поля: имя, телефон, выбранный язык и согласие на обработку персональных данных.

- Клиентская валидация показывает ошибки возле конкретных полей.
- Телефон отображается как `+7 (999) 999-99-99`; редактирование и удаление цифр корректно работают на любом участке, включая позицию после закрывающей скобки.
- Серверная обработка идёт через WordPress `admin-post.php` для авторизованных и неавторизованных посетителей.
- Используются nonce, sanitization, проверка обязательных полей, honeypot и ограничение частоты повторных отправок.
- Валидная заявка отправляется через `wp_mail()` на email администратора WordPress.
- Пользователь получает ясное сообщение об успехе или ошибке без раскрытия технических данных.

## Структура темы

- `style.css` с метаданными темы;
- `functions.php` с настройкой темы, подключением ресурсов и обработчиком формы;
- `header.php`, `front-page.php`, `footer.php`;
- `assets/css/main.css`, `assets/js/main.js`;
- `assets/images/` для сгенерированных изображений;
- `assets/icons/` для SVG-пиктограмм;
- `screenshot.png` для карточки темы в WordPress;
- `README.md` с установкой, настройкой почты и планом последующего подключения ACF.

## Проверка качества

- PHP syntax check для всех PHP-файлов.
- Проверка JavaScript и отсутствие ошибок в консоли.
- Проверка отправки формы на успешный и ошибочный сценарии.
- Визуальная проверка desktop, промежуточной ширины, 360 px и 320 px.
- Проверка бургер-меню, якорей, слайдера, маски телефона, клавиатуры и reduced motion.
- Сборка ZIP с единственной корневой папкой темы, пригодной для загрузки в WordPress.

## Границы текущего этапа

- ACF, панель управления содержимым и интеграция с CRM не входят в текущую версию.
- Реальная доставка писем зависит от почтовой конфигурации WordPress-хостинга; тема использует стандартный `wp_mail()`.
- Указанные в референсе показатели и отзывы воспроизводятся как предоставленный демонстрационный контент и не подтверждаются отдельно.
